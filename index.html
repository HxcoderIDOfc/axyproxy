FAQ

Pertanyaan Umum Developer

Apakah saya bisa langsung menggunakan library resmi openai? +
Ya, 100%! Baik di Python (pip install openai) maupun Node.js (npm install openai), Anda cukup mengarahkan baseURL: "https://api.axynera.my.id/v1" dan mengisi apiKey dengan kunci yang didapat setelah scan QRIS.
Bagaimana cara kerja pembayaran QRIS dan berapa lama prosesnya? +
Sistem akan otomatis menghasilkan barcode QRIS dinamis. Anda bisa scan menggunakan GoPay, OVO, DANA, BCA, Mandiri, BRI, atau mobile banking lainnya. Gateway kami mendeteksi settlement dalam hitungan detik dan API Key langsung diterbitkan di layar.
Apakah saldo atau kuota API Key memiliki masa kadaluarsa? +
Tidak ada masa kadaluarsa (lifetime validity). Kuota token dan batas generate gambar Anda tetap aktif selamanya sampai habis digunakan.
Bisakah digunakan untuk bot WhatsApp Baileys atau Telegram? +
Sangat bisa! Layanan ini sangat cocok untuk bot WhatsApp. Anda dapat mengirim teks pengguna maupun melampirkan foto gambar (Vision) langsung ke endpoint /v1/chat/completions dan menerima balasan instan.
