FAQ

Pertanyaan yang Sering Diajukan

Semua yang perlu Anda ketahui tentang integrasi API dan layanan Axynera.

Apakah saya bisa langsung memakai library resmi OpenAI? ▼
Ya, 100%! Anda hanya perlu mengubah parameter base_url="https://api.axynera.my.id/v1" dan memasukkan API Key yang Anda dapatkan setelah bayar QRIS. Format request dan response sama persis dengan spesifikasi standar OpenAI.
Bagaimana cara pembayaran QRIS dan berapa lama prosesnya? ▼
Saat Anda memilih paket, sistem akan otomatis menghasilkan kode QRIS dinamis. Anda bisa scan memakai GoPay, OVO, DANA, BCA, Mandiri, ShopeePay, atau bank apa saja. Sistem akan mendeteksi pembayaran secara real-time dan API Key langsung muncul di layar Anda.
Apakah ada masa kadaluarsa (expired) untuk API Key saya? ▼
Tidak ada! Saldo kuota token dan limit gambar yang Anda beli aktif selamanya sampai kuota tersebut habis Anda gunakan.
Bisakah dipakai untuk bot WhatsApp Baileys? ▼
Sangat bisa! Axynera dirancang khusus agar mudah dipakai di bot WhatsApp (Baileys/Wwebjs). Mendukung chat auto-reply, membaca gambar yang dikirim pengguna di chat (Vision), serta membuat stiker/gambar otomatis dengan Axynity-Image.
Bagaimana cara mengecek sisa saldo atau menguji key saya? ▼
Anda dapat membuka Playground Studio kami kapan saja. Di sana Anda bisa memasukkan key Anda, mengecek statusnya, serta mencoba chat dan generate gambar langsung di browser.
