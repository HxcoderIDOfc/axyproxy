Frequently answered technical questions

Is this strictly compatible with the official OpenAI client SDKs? +
Yes. Both Python (openai) and TypeScript/JavaScript (openai npm package) can connect by simply overriding the baseURL parameter to https://api.axynera.my.id/v1. Streaming (SSE), temperature, top_p, and JSON responses behave identically.
How are API keys generated and authenticated without recurring cards? +
Upon successful settlement via QRIS, the system issues a cryptographically signed key (axy-live-...) using HMAC-SHA256. Edge functions verify this signature with zero database latency, guaranteeing immediate authorization across all edge nodes.
Do purchased token balances expire? +
No. Quota remains valid permanently until consumed by API requests. There are no monthly reset cycles or forced forfeiture.
Can I use this for WhatsApp Baileys or Telegram bots? +
Yes. The gateway is specifically optimized for low overhead in messaging bots. You can pass user text or base64 images directly to /v1/chat/completions and receive clean strings ready for WhatsApp message dispatching.
