⚡ Quickstart (OpenAI Compatible)

API Axynera 100% kompatibel dengan SDK resmi OpenAI (Python, Node.js, cURL). Anda cukup mengganti baseURL ke domain Axynera:

Python (OpenAI SDK):
from openai import OpenAI

client = OpenAI(
    base_url="https://api.axynera.my.id/v1",
    api_key="axy-key-tes123" # atau API Key QRIS kamu
)

response = client.chat.completions.create(
    model="Axynity-M1",
    messages=[
        {"role": "user", "content": "Halo! Siapa kamu?"}
    ]
)

print(response.choices[0].message.content)

💬 Chat Completions (/v1/chat/completions)

Endpoint untuk chat interaktif, coding, penalaran mendalam, serta Vision multimodal (gambar base64 atau URL).

Node.js / JavaScript (Fetch):
const res = await fetch("https://api.axynera.my.id/v1/chat/completions", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer axy-key-tes123"
  },
  body: JSON.stringify({
    model: "Axynity-M1",
    messages: [
      { role: "user", content: "Buatkan puisi singkat tentang teknologi" }
    ],
    temperature: 0.7
  })
});
const data = await res.json();
console.log(data.choices[0].message.content);

🤖 WhatsApp Bot (Baileys Integration)

Integrasi langsung ke bot Baileys WhatsApp Anda dengan support Auto Reaction, Vision, dan Image generation:

import axios from "axios";

async function askAxynity(prompt, imageBase64 = null) {
  const content = [];
  if (imageBase64) {
    content.push({
      type: "image_url",
      image_url: { url: `data:image/jpeg;base64,${imageBase64}` }
    });
  }
  content.push({ type: "text", text: prompt });

  const res = await axios.post("https://api.axynera.my.id/v1/chat/completions", {
    model: "Axynity-M1",
    messages: [{ role: "user", content }]
  }, {
    headers: { "Authorization": "Bearer axy-key-tes123" }
  });

  return res.data.choices[0].message.content;
}
